## 背景

v0.1 编写时联网检索不可用，候选表全部标 `⚠️核验`。v0.2 已完成 GitHub / Hugging Face / arXiv 在线核验，需要把「凭印象选型」改为「同台实测 + 评分卡」决策。

## 决策

1. **双轨路线不变**：轨道 A（可控基座 / 控制面）+ 轨道 B（LoRA 定制 / 音色资产），由 L5 `VoiceSpec` 契约解耦，换基座不动上层。
2. **轨道 A 候选收敛为宽松许可权重三选一**：`CosyVoice 2`（Apache-2.0，`2407.05407`/`2412.10117`）、`Qwen3-TTS`（Apache-2.0）、`VoxCPM2`（Apache-2.0，`2509.24650`）。
3. **方法参考但不直接采用其权重**：`IndexTTS2`（`2506.21619`，三路解耦 + 精确时长，bilibili 许可待法务）、`Spark-TTS`（`2503.01710`，属性级控制，权重 CC-BY-NC-SA-4.0 依 ADR-0001 排除）。
4. **评分卡（v0.2 修订）**：

| 维度 | 权重 | 论文依据 |
| --- | --- | --- |
| 参数可控性（覆盖 / 解耦 / 单调性） | 25% | FastSpeech 2 `2006.04558`、IndexTTS2 `2506.21619` |
| 解耦表示（factorized / decoupled tokens） | 10% | NaturalSpeech 3 `2403.03100`、Spark-TTS `2503.01710` |
| 参数可枚举性 | 10% | PromptTTS 2 `2309.02285`、InstructTTS `2301.13662` |
| 中文自然度与可懂度 | 15% | AISHELL-3 `2010.11567`、WenetSpeech `2110.03370` |
| 零样本相似度 | 10% | VALL-E `2301.02111`、Seed-TTS `2406.02430` |
| 微调友好度 | 10% | LoRA `2106.09685` |
| 流式与延迟 | 10% | CosyVoice 2 `2412.10117` |
| 许可证（含可否叠加 NC 增量） | 10% | ADR-0001 / 许可证矩阵 |
| 社区活跃 | 5% | — |

5. **一票否决**：权重不可获取、训练代码缺失导致无法复现、许可证与本项目 NC 定位冲突且法务无法确认。
6. **实测要求**：同一份固定回归集、同一硬件、同一套指标（Q1–Q10），3 候选同台跑分；禁止凭印象定选型。所有阈值在 Phase 2 用基线实测校准，校准只能收紧。
